# 轨道交通示意图编辑器（Metro Map Designer）

一个纯前端单页应用，用于绘制官方线路图风格（45°/90° 折线）的城市轨道交通示意图。适合城市交通规划自媒体作者快速产出风格化的虚拟地铁线路图。

## 技术栈

- Vue 3（组合式 API）+ Vite
- Element Plus（UI 组件）
- Pinia（状态管理，含撤销/重做历史）
- SVG 画布渲染
- localStorage 自动持久化当前作品，无后端

## 功能列表

- **无限网格画布**：滚轮缩放（以鼠标为中心）、拖拽空白处平移，站点自动吸附网格
- **线路绘制**：新建线路（名称 + 颜色）后依次点击画布放置站点；站间连线自动按 45°/90° 曼哈顿折线布线，任何情况下不会出现任意斜率的线段，拖动站点实时重算
- **站点编辑**：拖动站点、双击线段在中途插入站点、删除站点后自动重连前后站点
- **换乘站**：多条线路经过同一网格坐标自动合并为胶囊形换乘站，内部显示经过线路的色条；拖动一个站点到另一站点上也可合并
- **交叉跨越**：线路交叉但无站点时，绘制层级较低的线路在交叉点显示白色断口，呈现"上层线路跨越"效果
- **站名标签**：支持 8 个方位调整；「标签防重叠」按钮自动把互相重叠的标签换方位移开
- **属性编辑**：站名、标签方位、是否终点站（加粗端点样式）；线路改名、调色、显隐、层级上移/下移、删除
- **撤销/重做**：不少于 50 步（上限 100 步），工具栏按钮 + 快捷键 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z（或 Ctrl+Y），删除换乘站等复合操作为原子一步
- **导入导出**：导出/导入 JSON 存档继续编辑；导出整图为独立 SVG 文件（含全部可见线路与站名，隐藏线路不导出，浏览器可直接打开）
- **示例作品**：首次打开自动加载虚拟城市「云港市」示例（3 条线路、14 个站点、2 个换乘站）

## 启动命令

```bash
npm install     # 安装依赖
npm run dev     # 启动开发服务器（默认 http://localhost:5173）
npm run build   # 构建生产版本到 dist/
```

## 操作速查

| 操作 | 方式 |
| --- | --- |
| 放置站点 | 绘制模式下点击画布（自动吸附网格） |
| 结束绘制 | Esc 或工具栏「完成绘制」 |
| 选中站点/线段 | 选择模式下点击 |
| 移动站点 | 选择模式下拖动站点 |
| 中途插入站点 | 双击线段 |
| 删除站点 | 选中后按 Delete，或在属性面板点「删除站点」 |
| 撤销 / 重做 | Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z |

## 目录结构

```
src/
├── main.js                  # 入口，注册 Pinia / Element Plus，订阅自动保存
├── App.vue                  # 整体布局
├── store/metro.js           # Pinia 仓库：数据模型、撤销重做、换乘合并、持久化
├── utils/geometry.js        # 45°/90° 折线布线、线段相交、标签包围盒
├── utils/sampleData.js      # 内置示例作品
└── components/
    ├── MetroCanvas.vue      # SVG 画布：缩放平移、线路/站点/标签渲染、交互
    ├── Toolbar.vue          # 工具栏：新建线路、撤销重做、防重叠、导入导出
    ├── LineList.vue         # 线路列表面板
    └── PropertyPanel.vue    # 属性面板（站点/线段/线路）
```
